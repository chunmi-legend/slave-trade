# slave-trade

중학교 2학년을 위한 대서양 노예무역 교육용 웹사이트입니다. `index.html`을 브라우저로 열면 바로 실행돼요.

## 사료와 참고문헌 넣는 법

사료 카드와 참고문헌은 `index.html` 안의 `<script>` 맨 위에 있는 **입력 칸 한 곳**만 고치면 돼요.
(파일에서 `✍️ 사료 읽기 · 참고문헌 입력 칸`을 찾으세요.)

### 1. 사료 읽기 카드 (`SOURCES`)

'중간 항로와 저항의 역사' 페이지에 사료 카드를 넣을 자리가 6곳 있어요.

| slot | 들어가는 곳 | 추천 사료 |
|---|---|---|
| `triangle` | 삼각무역 | 노예선 화물 목록, 상인의 장부·편지 |
| `middle-passage` | 중간 항로 | 에퀴아노 자서전(1789) 노예선 장면, 브룩스호 도면(1788), 팔콘브리지의 증언(1788) |
| `voice` | 끌려간 사람의 목소리 | 에퀴아노 자서전의 납치 장면 |
| `resistance` | 멈추지 않은 저항 | 아이티 독립 선언문(1804), 투생 루베르튀르의 포고문 |
| `abolition` | 폐지까지의 긴 길 | 웨지우드 메달(1787), 윌리엄 폭스의 소책자(1791) |
| `africa` | 아프리카에 남은 상처 | 콩고 왕 아폰수 1세의 편지(1526) |

- `title`과 함께 `text`(번역문)나 `image`(그림) 가운데 하나를 채우면 카드가 나타나요.
- 비어 있는 칸은 **학생 화면에 보이지 않아요.**
- 그림은 `images/sources/` 폴더에 올리고, 그림을 넣었다면 `credit`(출처)을 꼭 채워요.

### 2. 참고문헌 (`REFERENCES`)

`primary`(1차 사료), `studies`(연구서·논문), `web`(데이터베이스·웹사이트), `images`(그림·영상 출처)로 나뉘어 있어요.
`{ text: '…', note: '어디에 썼는지' }` 형식으로 한 줄씩 추가하세요. 홈과 역사 읽기 페이지 아래의
'참고문헌과 그림 출처 보기'(`#references`)에 나타나요.

### 3. 작성 모드로 확인하기

주소 끝에 `?draft`를 붙이면 빈 칸 자리와 추천 사료, 빠진 그림 출처 경고가 보여요.

- 예) `https://(사이트 주소)/?draft#history` (역사 읽기)
- 예) `https://(사이트 주소)/?draft#references` (참고문헌)

`?draft` 없이 열면 학생이 보는 화면 그대로예요.
